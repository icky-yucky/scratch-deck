# Third-party notices

Scratch Deck's own source code is MIT licensed — see [LICENSE](LICENSE).

The packaged Windows builds are not just that source. They ship the Electron
runtime, which embeds Chromium and Node.js, and those carry their own licenses
and attribution requirements. This file records what is redistributed and where
the full notice texts live.

## Bundled in the Windows builds

| Component | License | Notice file shipped with the app |
| --- | --- | --- |
| Electron | MIT | `LICENSE.electron.txt` |
| Chromium + its third-party dependencies | BSD-3-Clause, plus many others | `LICENSES.chromium.html` |
| Node.js (embedded in Electron) | MIT | covered by the two files above |

Both notice files are placed next to the executable by `electron-builder`; they
are not generated by hand and should not be edited. `LICENSES.chromium.html` is
the full Chromium **Credits** page — around 20 MB, listing every third-party
component Chromium itself vendors, each with its own license text.

## Where to find them

- **Installer build** (`Scratch.Deck.Setup.<version>.exe`) — in the installation
  directory you chose, alongside `Scratch Deck.exe`.
- **Portable build** (`ScratchDeck-portable-<version>.exe`) — the portable
  executable unpacks itself to a temporary directory at launch, so the notice
  files are present but not somewhere you would stumble across them. To read
  them without running the app, open the `.exe` with 7-Zip and extract
  `$PLUGINSDIR/app-64.7z`; both files sit at its root.

## No bundled npm dependencies

`package.json` declares no runtime `dependencies`. `electron` and
`electron-builder` are `devDependencies` used only to build the app, and are not
redistributed — apart from the Electron runtime itself, which is what this file
covers.

## Audio engine

The WSOLA time-stretching engine is original code written for this project. It
implements a published algorithm (Waveform Similarity Overlap-Add, Verhelst and
Roelands, 1993); the algorithm is not itself subject to copyright, and no
third-party WSOLA implementation was copied or adapted.
